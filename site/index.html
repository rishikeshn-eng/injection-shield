Injection Shield

A small classifier that flags indirect prompt injection: instructions hidden in web pages, emails, API responses, code and agent memory that try to hijack an AI agent. It runs entirely in your browser (quantised ONNX, ~33 MB), so nothing you paste leaves the page. Code, data recipe and full results on GitHub.

In plain words

AI assistants read web pages and emails for you. Some of those pages whisper orders to the AI. This small model listens for the whispers before the AI acts on them.
