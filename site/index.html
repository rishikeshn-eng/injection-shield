Injection Shield

A small classifier that flags indirect prompt injection: instructions hidden in web pages, emails, API responses, code and agent memory that try to hijack an AI agent. It runs entirely in your browser (quantised ONNX, ~33 MB), so nothing you paste leaves the page. Code, data recipe and full results on GitHub.

OOD style = 4 attack styles never seen in training (memory poisoning, obfuscation, persuasion, fake dialogue turns). OOD carrier = 3 document formats never seen in training (calendar invites, logs, CSV). InjecAgent and AgentDojo are external benchmarks never used for training. Hard negatives = benign documents with imperative language, security articles, legitimate bot config (FPR only). Brackets: 95% bootstrap CI.
